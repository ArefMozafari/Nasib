Nasib 1.0.0 runs one shared engine on every platform, searches every Windscribe datacenter in your order, tries other ports when the usual ones are blocked, and comes to Linux as a preview.

**What's new**
- **One engine everywhere**: the search now runs in `nasib-engine`, a Rust program that macOS, Windows and Linux all share, so each platform finds servers the same way.
- **Every datacenter, in your order**: Settings lists every Windscribe datacenter (about 200), grouped by region, with search, Select all and Deselect all. Check the ones to search and put them in order. "Rank by recent success" tries the ones that worked best lately first; turn it off to follow your order exactly. Cities saved by an older version carry over as the same locations.
- **Other ports**: when nothing works on each protocol's usual port, a second pass tries its other ports, the ones that worked before first. The port of every attempt shows in the output and in `log.csv`.
- **Stages in the output**: a teal line marks each stage of a search as it starts.
- **Linux (preview)**: a GTK 4 app with the same tabs, tray menu and behavior, as `.deb`, `.rpm` and `.tar.gz` for x64. It installs and starts on Ubuntu 22.04 and Fedora 38, but hasn't been tested on a real Windscribe connection yet. Reports are welcome in the issues.

**Before you update**
- Going back to an older version after this one isn't clean. An older version can't take the run lock this one leaves as a file named `lock` in Nasib's folder (`~/.ws-find` on macOS); delete it if an older version says a search is already running. An older version also drops attempts logged with a port from its rankings.
- When nothing works, a search can take much longer than before, since it goes on to every other port. A survey always covers every port, so it takes several times longer.

**Downloads**
- `Nasib-1.0.0-macos.zip`: macOS 15 or later, Apple silicon
- `Nasib-1.0.0-win-x64.zip`: Windows on x64, self-contained, no .NET install needed
- `Nasib-1.0.0-linux-x64.deb`: Ubuntu 22.04+, Debian 12, Linux Mint 21+ (`sudo apt install ./Nasib-1.0.0-linux-x64.deb`)
- `Nasib-1.0.0-linux-x64.rpm`: Fedora 38+ (`sudo dnf install ./Nasib-1.0.0-linux-x64.rpm`)
- `Nasib-1.0.0-linux-x64.tar.gz`: other distros; unpack and run `./nasib/install.sh`

Every build needs the Windscribe app, installed and logged in. Windscribe's Anti-Censorship options can't be set from its command line, so set them once in the Windscribe app.

No build is signed by a known publisher. On macOS, allow it once under System Settings → Privacy & Security → Open Anyway, or run `xattr -dr com.apple.quarantine /Applications/Nasib.app`. On Windows, SmartScreen may warn on first launch; choose More info → Run anyway.
